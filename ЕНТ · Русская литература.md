# ЕНТ · Русская литература — подготовка

Интерактивный веб-тренажёр и справочник для подготовки к ЕНТ по русской литературе:
- план занятий по неделям и темам;
- тесты и пробные варианты;
- журнал ошибок;
- справочник тропов, родов и направлений литературы.

## Запуск
Откройте `index.html` в браузере или перейдите по ссылке опубликованного сайта. Прогресс хранится локально в браузере (`localStorage`).
